# SaaS example

A complete project generated by codebuild from the specs in `specs/`: organizations, users, tags (many-to-many with users) and projects. It targets Go 1.26 and PostgreSQL.

Everything except `specs/`, `internal/*/service.go`, `cmd/`, `internal/platform/config` and `internal/platform/database/database.go` is generated. `internal/users/service.go` shows how to add a business rule: it normalizes email addresses before they reach the generated repository.

## Run it

```bash
docker run --rm -d --name saas-db -e POSTGRES_USER=app -e POSTGRES_PASSWORD=app -e POSTGRES_DB=app -p 5432:5432 postgres:17
export DATABASE_URL='postgres://app:app@localhost:5432/app?sslmode=disable'
go run ./cmd/migrate up
go run ./cmd/api
```

```bash
curl -s -X POST localhost:8080/orgs -d '{"name":"Acme","slug":"acme"}'
```

## Regenerate

From the repository root:

```bash
go run ./cmd/codebuild build --dir examples/saas
```

CI runs `codebuild plan --exit-code --dir examples/saas` to make sure the committed code matches the specs.
